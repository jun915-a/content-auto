# pg_durable Open Sourced

Microsoft releases pg_durable, enabling in-database durable execution for improved reliability and performance

## The Core of This Topic
pg_durable is Microsoft's solution for in-database durable execution, enhancing the reliability and efficiency of database operations.
## 5-Second Key Points
- **Reliability**: Ensures database consistency
- **Performance**: Improves execution speed
- **Open Source**: Available on GitHub
## Detailed Breakdown
**In-Database Execution**
pg_durable allows for durable execution directly within the database, streamlining processes.
**Durable Execution**
This approach minimizes the risk of data loss and inconsistencies, providing a robust framework for database operations.
> Insight: By integrating durable execution into the database, pg_durable simplifies the development of reliable applications.
