# Pushing the Limits of a $8 Microcontroller

A groundbreaking experiment to run a 28.9M parameter LLM on an $8 microcontroller.

## 🔑 The Core of This Topic
Running a large language model (LLM) on a low-cost microcontroller is a remarkable feat, pushing the boundaries of what is thought to be possible. The ESP32 microcontroller, available for under $8, is being used as a testbed for this ambitious project.

- **Point 1**: The ESP32 is a low-power, low-cost microcontroller.
- **Point 2**: The 28.9M parameter LLM is a significant challenge to run.
- **Point 3**: The project aims to make AI more accessible.

The ESP32's capabilities make it an attractive choice for running LLMs. Its low power consumption and high performance enable it to handle complex tasks like language processing.
