# TurboFieldfare: AI on M-Series Macs

Run Gemma 4 26B-A4B-IT on any M-series Mac with 2 GB RAM using TurboFieldfare

## The Core of This Topic
TurboFieldfare is a specialized inference engine for running 4-bit Gemma 4 26B-A4B-IT models.

- **High Performance**: Fast inference on M-series Macs
- **Low Memory**: Uses about 2 GB of RAM
- **Open-Source**: Written in Swift and Metal, available on GitHub

TurboFieldfare is designed for efficiency, leveraging Metal for optimized performance.
**Model Support**
Supports 4-bit Gemma 4 26B-A4B-IT models for various applications.
