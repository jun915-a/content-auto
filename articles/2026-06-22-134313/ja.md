# **Manticore Search 27.1.5: アーカイブ検索と分散化を強化**

Manticore Search 27.1.5 の新機能は、検索とインデックス管理を改善するだけでなく、より高速なベクトル検索と対話型検索のサポートも提供します。このアップデートは、ユーザー エクスペリエンスとパフォーマンスを向上させるために、重要な改善を含んでいます。

## このトピックの本質
Manticore Search 27.1.5 は、検索とインデックス管理を強化するだけでなく、ベクトル検索と対話型検索のサポートを追加する新しい機能を提供します。

## 5秒で分かるポイント
- **Point 1**: 分散化されたアーカイブ検索をサポートする
- **Point 2**: ベクトル検索のパフォーマンスを大幅に向上させる
- **Point 3**: 対話型検索のサポートを追加する

## 詳細解説
**Auth**
Manticore Search 27.1.5 では、ユーザー認証をサポートすることができます。ユーザー認証は、データベースにアクセスするユーザーを管理するために重要な機能です。

**sharding**
このアップデートでは、分散化されたアーカイブ検索をサポートする sharding 機能が追加されました。sharding は、データベースを分割して管理し、パフォーマンスを向上させるために使用される技術です。

**conversational search**
Manticore Search 27.1.5 では、対話型検索のサポートを追加することができます。対話型検索は、ユーザーが自然な言語で検索する際に使用される機能です。

**faster vector search**
ベクトル検索のパフォーマンスを大幅に向上させる機能が追加されています。ベクトル検索は、ユーザーが特定のデータを検索する際に使用される機能です。
