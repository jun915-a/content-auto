# Times New Bastard: Abusing Ligatures for Cursed Fonts

Explore the hilarious and 'cursed' font generator, Times New Bastard. This tool cleverly uses OpenType ligatures to mash fonts together, all running client-side with Python in WASM.

## 🔑 The Core of This Topic
Times New Bastard is a playful tool that exploits the OpenType ligature feature, typically used for character combinations, to blend different fonts. It creates "cursed" or "bastardized" font styles by merging characters in unexpected ways, offering a unique and humorous typographic experiment.

## ⚡ 5-Second Key Points
- **Font Abuse**: Leverages OpenType ligatures for unconventional font mixing.
- **Cursed Aesthetics**: Generates unique, often jarring, font "bastards".
- **Client-Side Power**: Utilizes Python compiled to WASM for fast, browser-based operation.

## 📈 Detailed Breakdown
**The Ligature Trick**
Ligatures are designed to improve text flow by combining specific character pairs (like 'fi' or 'fl'). This tool hijacks that mechanism, feeding it font pairs that result in bizarre visual mashups instead of smooth transitions, leading to "cursed" outputs.

**Python in WASM**
Running complex font manipulation logic directly in the browser is challenging. By compiling Python to WebAssembly (WASM), the tool achieves impressive client-side performance, allowing for quick font generation without server reliance.
