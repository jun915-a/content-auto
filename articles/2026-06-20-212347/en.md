# AMD Revives Memory Encryption on Ryzen 9000 CPUs

AMD will reinstate memory encryption on Ryzen 9000 processors via BIOS update in July, a move welcomed by the community.

## ✨ Conclusion
AMD's decision to reinstate memory encryption on Ryzen 9000 CPUs is a welcome move that shows the company is committed to listening to community feedback and providing the security features that users need.
