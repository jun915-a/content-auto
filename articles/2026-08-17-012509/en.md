## 📈 Detailed Breakdown
**Work Units**: DuckDB's asynchronous I/O is built around work units, which are the basic building blocks of I/O operations. These work units are executed concurrently, allowing for efficient handling of complex queries.
   
**Thread Pools**: DuckDB uses thread pools to manage the execution of work units. This ensures that work units are executed efficiently and without resource contention.
