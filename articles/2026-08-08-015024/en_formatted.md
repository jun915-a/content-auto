## 📈 Detailed Breakdown
**Buffer Overflow Attacks**
A buffer overflow attack occurs when more data is written to a buffer than it can hold, causing the extra data to spill over into adjacent memory locations. This can overwrite sensitive information, such as passwords or authentication tokens, allowing an attacker to gain unauthorized access to a system.

**Format String Vulnerabilities**
Format string vulnerabilities occur when an attacker is able to manipulate the format string used to print data to the console. This can be used to extract sensitive information from the system, such as memory addresses or credentials.

> 💡 Insight: The key takeaway from these vulnerabilities is that even the most seemingly innocuous errors can have devastating consequences.
