# Building a 16-bit Magnetic Core Memory: A DIY Retro Tech Masterpiece

Dive into the fascinating world of vintage computing with this hands-on guide to constructing a fully functional 16-bit magnetic core memory. Perfect for tech enthusiasts and historians alike, this project bridges the gap between analog and digital eras—revealing the raw power of magnetic storage from the 1960s.

## 🔑 The Core of This Topic
Magnetic core memory was the backbone of early computers, offering **reliable, non-volatile storage** before transistors dominated. Unlike modern DRAM or flash, these tiny **ferrite rings** stored binary data via magnetic fields—each ring representing a single bit. This YouTube project breathes new life into this forgotten technology, proving its enduring charm and educational value for modern engineers and hobbyists.

## ⚡ 5-Second Key Points
- **Magnetic rings** act as binary switches (0/1) via magnetic polarity.
- **16-bit storage** demonstrates core memory’s scalability in vintage systems.
- **DIY-friendly** design uses accessible materials and simple wiring.

## 📈 Detailed Breakdown
**Element 1: The Ferrite Rings and Magnetic Fields**
Each ferrite ring in this memory module is a **tiny magnetic loop** that can be magnetized in two directions, representing 0 or 1. When a current passes through a wire wound around the ring, it flips its polarity—this is the essence of read/write operations. The project cleverly uses **coaxial cables** to guide currents precisely, ensuring minimal interference. The simplicity of this design highlights why core memory was so robust: **no moving parts** meant durability far beyond early mechanical storage.

**Element 2: Addressing and Read/Write Logic**
To access a specific bit, the system uses **selective activation** of wires. A unique combination of currents targets a single ring, allowing the module to read or write data. The 16-bit configuration means **4 address lines** (2⁴ = 16) control which ring is active. This logic mirrors early computer architectures like the **PDP-8**, making it a tangible lesson in vintage computing.

> 💡 Insight: **Core memory’s parallelism** allowed simultaneous access to multiple bits, a concept still relevant in modern multi-core processors.
