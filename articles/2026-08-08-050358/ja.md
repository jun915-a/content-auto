ガード付きメソッドは、特定の条件に基づいてメソッドの実行を制御できる機能です。ガード付きメソッドを使用するには、メソッドの関数定義に条件を指定する必要があります。

**ガード付きメソッドの実例**
以下は、ガード付きメソッドの実例です。
```ocaml
type person = {
  name: string;
  age: int;
}

let get_name (person: person) =
  match person.age with
  | 0 -> "baby"
  | 1 -> "child"
  | _ -> person.name
```
このコードでは、`person`オブジェクトの`age`フィールドに基づいて、`get_name`関数が実行されます。
