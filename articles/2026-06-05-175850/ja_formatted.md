# Meta、 PortalデバイスにADBを有効にする

*ここに見出し画像を挿入*

Metaは、Portalデバイスの開発者向けにADB（Android Debug Bridge）を有効にしました。この機能により、開発者はPortalデバイスでのアプリのテストとデバッグが容易になります。MetaのHorizonブログでは、AIを使用したPortalアプリの開発方法についても紹介しています。この機能の追加により、開発者はより効率的な開発プロセスを実現できるようになります。
