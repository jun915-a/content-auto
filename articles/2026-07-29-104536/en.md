# Cracking Windows Open: Porting RADV to Win32

Collabora is working on porting the RADV open-source graphics driver to Windows 32-bit, enabling Vulkan support on the platform.

## 🔑 The Core of This Topic
Collabora's mission to bring open-source graphics drivers to various platforms has led to an exciting new project: porting the RADV driver to Windows 32-bit. This effort will provide Vulkan support on the Windows platform, allowing developers to leverage the power of open-source graphics drivers.

RADV is an open-source driver developed by the AMD Radeon team, and its port to Windows 32-bit will enable developers to create games and applications that take advantage of the Vulkan API on Windows.
