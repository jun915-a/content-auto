# Hearing Shape as Sound with Eigendrum

A web tool that turns arbitrary shapes into drums, showcasing a unique blend of physics and sound.

## 🔑 The Core of This Topic
Eigendrum is a web tool that applies mathematical physics to create an immersive experience, allowing users to hear what any shape sounds like as a drum. This is achieved by solving the 2D wave equation for arbitrary shapes using finite element analysis.

## ⚡ 5-Second Key Points
- **Point 1**: Solves the 2D wave equation using finite element analysis.
- **Point 2**: Generates unique drum sounds for any input shape.
- **Point 3**: A user-friendly web interface makes it accessible to everyone.

## 📈 Detailed Breakdown
**Element 1**: The 2D wave equation is a fundamental concept in physics that describes how waves propagate through a medium. In this context, it's used to calculate the vibrations of a drumhead when struck by a mallet. By applying finite element analysis, Eigendrum can solve this equation for any shape, allowing users to hear the resulting sound.

**Element 2**: The web interface of Eigendrum is designed to be user-friendly and intuitive. Users can simply draw any shape using the provided tools, and the tool will generate a unique drum sound in real-time.
