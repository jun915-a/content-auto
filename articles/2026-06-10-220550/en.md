# Claude Desktop Issue

Claude Desktop spawns a 1.8 GB Hyper-V VM on every launch, causing concerns for users with limited resources, even when only using chat features

## 🔑 The Core of This Topic
Claude Desktop is spawning a large Hyper-V VM on every launch, which is unnecessary for chat-only use.
## ⚡ 5-Second Key Points
- **Point 1**: Large VM size of 1.8 GB
- **Point 2**: Unnecessary for chat-only use
- **Point 3**: Concerns for users with limited resources
## 📈 Detailed Breakdown
**Element 1**: The large VM size is a significant issue for users with limited disk space or bandwidth.
**Element 2**: The unnecessary VM spawn for chat-only use is a waste of resources and can lead to performance issues.
> 💡 Insight: Optimizing the launch process can greatly improve user experience.
## 🎯 Real-World Impact
- Increased resource usage
- Potential performance issues
- Negative impact on user experience
## ✨ Conclusion
The issue of Claude Desktop spawning a large Hyper-V VM on every launch needs to be addressed to improve user experience and resource efficiency.
