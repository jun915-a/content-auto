# 冷蔵庫に貼る、電子ペーパー製ショッピングリスト！

*ここに見出し画像を挿入*

M5Stack PaperMono を使った、冷蔵庫に貼れる電子ペーパー製ショッピングリストです。Wi-Fi や BLE に対応し、スマートフォンとも連携可能。オフラインでも使え、約 2,400 行の C++ で実現されています。このデバイスは、便利でエコな暮らしを実現します。

## 📊 詳細解説
**ハードウェア**
M5Stack PaperMono は、ESP32-S3 チップと電子ペーパー ディスプレイを搭載。タッチスクリーンに対応し、冷蔵庫に貼り付ける磁石も内蔵しています。

**ソフトウェア**
約 2,400 行の C++ で開発され、Wi-Fi 経由でスマートフォンと通信。オフラインでも利用でき、リストの管理や編集が可能です。

> 💡 ポイント: 紙のリストの代わりに、環境に優しく、利便性の高いショッピングリストを実現します。

## 🚀 実世界への影響
- 紙のリストを使わなくなることで、環境への負荷を軽減。
- いつでもリストを確認できるので、買い忘れを防ぎ、無駄な買い物を減らします。
- スマートフォンとの連携で、家族やルームメイトとリストを共有し、買い物を分担できます。
