# Compile Lua to Native Executables with Clx

A C++20 ahead-of-time compiler for standard Lua that generates standalone native executables through GCC, Clang, or MSVC.

## 🔑 The Core of This Topic
Clx is a novel ahead-of-time compiler that compiles standard Lua to native executables. This project began as an experiment to see what was possible with the latest C++20 features.
