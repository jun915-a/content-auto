# **TLS 1.2とDTLS 1.2の古い鍵交換方法の非推奨**

RFC 10015が提示する、TLS 1.2とDTLS 1.2の古い鍵交換方法の非推奨についての概要。TLS/DTLSのセキュリティと互換性の改善に大きな影響を与える草案。

## 📌 このトピックの本質
RFC 10015では、TLS 1.2およびDTLS 1.2の古い鍵交換方法を非推奨に制定することを提案しています。これらの鍵交換方法は、セキュリティと互換性の向上に大きな影響を与える可能性があります。

## 📊 詳細解説
**TLS 1.2の古い鍵交換方法**
TLS 1.2では、古い鍵交換方法であるRSA key exchangeとPSK (Pre-Shared Key) key exchangeが利用可能でした。ただし、これらの方法はセキュリティ上の欠陥があり、非推奨に制定される予定です。

**DTLS 1.2の古い鍵交換方法**
DTLS 1.2でも、古い鍵交換方法が利用可能でした。DTLS 1.2の古い鍵交換方法は、TLS 1.2と同様に非推奨になります。
