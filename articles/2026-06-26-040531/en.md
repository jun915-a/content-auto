# Migrate from Proxmox to NixOS and Incubator

Say goodbye to Proxmox and hello to a more scalable and customizable infrastructure with NixOS and Incubator.

## 🔑 The Core of This Topic
NixOS and Incubator offer a more scalable and customizable infrastructure compared to Proxmox. By migrating to NixOS, you can enjoy a declarative configuration model, a package manager, and a rolling release model.
