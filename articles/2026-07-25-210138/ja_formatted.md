# macOS用AIアージェントが住むテキストエディター「Yorishiro」

*ここに見出し画像を挿入*

macOS用のオープンソーステキストエディター「Yorishiro」が登場。AIアージェントがテキストエディター内に住み込むという一目見ろのアイデア。Claude Code / Codexと連携し、ユーザーがAIと対話することが可能になる

## 📊 詳細解説

YorishiroはmacOS用のオープンソーステキストエディターです。

AIアージェントは、ユーザーが入力するテキストに応じて、ユーザーに情報を提供することができます。

ユーザーはAIと対話することができ、ユーザーの仕事をサポートすることができます。
