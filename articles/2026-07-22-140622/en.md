# Apollo 11 Code Released

The original Apollo 11 Guidance Computer source code is now available, offering insights into the historic mission's technology and development

## The Core of This Topic
The Apollo 11 Guidance Computer source code is a significant piece of history, containing the commands and lunar modules that made the first moon landing possible.
## 5-Second Key Points

- **Technical Complexity**: Complex computer code
- **Open Source**: Available on GitHub
## Detailed Breakdown
**Command Module**
The command module contained the main computer that controlled the spacecraft.
**Lunar Module**
The lunar module computer handled the descent and landing on the moon.
