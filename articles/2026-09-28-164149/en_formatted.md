# Hntui: A Fresh TUI for Hacker News Built with OpenTUI & Effect

*Insert header image here*

Discover **Hntui**, a sleek terminal UI for Hacker News crafted with **OpenTUI** and **Effect**—a learning experiment that redefines how you browse HN. Lightweight, fast, and packed with modern features, it’s a must-try for developers and HN enthusiasts alike.

**Hntui** is a terminal-based UI (TUI) for Hacker News, showcasing how modern frontend tooling like **OpenTUI** and **Effect** can transform a classic text interface. Built as a learning project, it proves that even simple tools can be elegant when designed with intentionality and cutting-edge tech.
