# Oracle Bans AI-Generated Code from OpenJDK

Oracle has taken a stance against AI-generated code in OpenJDK, contradicting its CEO's previous claims.

## 🔑 The Core of This Topic
Oracle's decision to ban AI-generated code from OpenJDK has sparked controversy in the tech community. The move contradicts a previous statement by Oracle's CEO, Larry Ellison, who claimed that Oracle is not writing its own code. The ban is seen as a response to the growing use of AI-generated code in open-source projects.
