# 秒速で計算！日曜日を瞬時に見つける超高速アルゴリズム

プログラマーやデータサイエンティストに必須の日付計算。本記事では、ベン・ジョッフェが開発した**高速な日曜日計算アルゴリズム**を解説。Zellerの公式よりも**10倍速い**とされ、実装コードなしで原理を理解できる。日付処理のパフォーマンスを劇的に向上させよう！

## 📌 このトピックの本質

日曜日を瞬時に計算するアルゴリズムは、プログラミングや金融システムで**高速な日付処理**が求められる場面で必須。従来のZellerの公式は複雑で、計算コストが高い。ベン・ジョッフェの方法は**単純な数学演算**で日曜日を求め、計算時間を**大幅に短縮**する。このアルゴリズムは、グレゴリオ暦のルールを利用しつつ、**除算と加算のみ**で結果を導き出す。特に**大規模な日付範囲**を処理する際に、パフォーマンスの差が顕著に現れる。


## 🎯 5秒で分かるポイント
- **Point 1**: **除算と加算のみ**で日曜日を計算。複雑な乗算やモジュロ演算を省略
- **Point 2**: **1900年1月1日は木曜日**という基準を利用し、差分を計算
- **Point 3**: **年数の調整**で閏年の影響を考慮するが、簡易化されたルールで高速化


## 📊 詳細解説

**Element 1**

ベン・ジョッフェのアルゴリズムは、**1900年1月1日を基準日（木曜日）**として設定。この基準日から任意の日を**日数差**で表現し、その差分を**4つのステップ**で処理する。具体的には、

- **年数の調整**: 年数を4で割った余りを考慮し、閏年の影響を簡易的に補正
- **月数の調整**: 月数を3で割った余りを加算し、月ごとの日数差を反映
- **日数の加算**: 基準日からの総日数を加算
- **最終調整**: 総日数を7で割った余りで日曜日を決定

> 💡 ポイント: **閏年調整は年数の4で割った余り**のみで行うため、コード実装が**非常に簡潔**になる。


**Element 2**

アルゴリズムの**鍵となる部分**は、**月数の調整**と**年数の補正**。例えば、2023年12月31日は以下の計算で日曜日を求める:

1. **年数調整**: 2023 - 1900 = 123 → 123 ÷ 4 = 30余り3 → **3**を加算
2. **月数調整**: 12 ÷ 3 = 4余り0 → **0**を加算
3. **日数加算**: 31日を加算
4. **総和**: 3 + 0 + 365×123 + 31 = **1,413,000 + 34**
5. **最終調整**: 1,413,034 ÷ 7 = 余り6 → **木曜日 + 6日 = 日曜日**

> 💡 ポイント: **除算と加算のみ**で済むため、CPUの**高速演算**に最適。特に**ループ処理**で大量の日付を計算する際に威力を発揮する。
