## 🔑 The Core of This Topic
PlanetScale is a horizontally scalable database that allows for high availability and strong consistency. It's designed to provide a globally distributed database system that can handle large volumes of data and scale horizontally to meet the needs of a rapidly growing business.

## ⚡ 5-Second Key Points
- **Point 1**: Simplify database operations with a horizontal scaling model.
- **Point 2**: Achieve strong consistency across a globally distributed system.
- **Point 3**: Reduce latency by minimizing the number of hops between nodes.

## 📈 Detailed Breakdown
**Sharding**
Sharding is a technique used to divide a large database into smaller, more manageable pieces called shards. Each shard contains a portion of the data and can be scaled independently.

**Replication**
Replication is the process of maintaining multiple copies of data across a distributed system. This ensures that data is available even if one or more nodes fail.

> 💡 Insight: By combining sharding and replication, PlanetScale achieves both horizontal scalability and strong consistency.

## 🎯 Real-World Impact
- Reduced latency and improved response times for users.
- Increased scalability and ability to handle large volumes of data.
- Improved data availability and reduced risk of data loss.

## ✨ Conclusion
Building a scalable database infrastructure like PlanetScale from scratch requires a deep understanding of distributed systems and database architecture. By leveraging techniques like sharding and replication, developers can create a highly available and scalable database system that meets the needs of a rapidly growing business.
