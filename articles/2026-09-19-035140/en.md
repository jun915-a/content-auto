# Claude Code Now Reads AGENTS.md: Enhanced Documentation

Discover how Claude Code's documentation has evolved. Now, it intelligently reads AGENTS.md when Claude.md is absent, offering a more flexible and comprehensive developer experience.

## 🔑 The Core of This Topic
Claude Code's documentation system has been updated to be more flexible. If a project's primary Claude.md file is missing, the system will now automatically look for and read an AGENTS.md file instead, ensuring documentation is always accessible.

## ⚡ 5-Second Key Points
- **Flexible Documentation**: Claude Code now reads AGENTS.md if Claude.md is absent.
- **Improved Accessibility**: Ensures documentation is always available.
- **Streamlined Workflow**: Developers benefit from a more adaptive documentation system.

## 📈 Detailed Breakdown
**Adaptive File Reading**
Claude Code previously relied solely on a Claude.md file for project documentation. This update introduces adaptive behavior, allowing it to fall back to AGENTS.md, enhancing its robustness.

**Enhanced Developer Experience**
This change means developers can organize their documentation using either file naming convention without worrying about system compatibility. It simplifies setup and ensures critical information is discoverable.

> 💡 Insight: This update prioritizes developer convenience and adaptability in documentation management.

## 🎯 Real-World Impact
- Seamless integration for projects already using AGENTS.md.
- Reduced friction for new projects unsure of the preferred documentation file.
- More resilient documentation retrieval for the Claude Code ecosystem.

This small but significant change makes Claude Code's documentation system more user-friendly and adaptable, supporting a wider range of project structures.
