# Type-Safe SQL for Bun with Sqlgen

Discover a new way to interact with databases in Bun using Bun-sqlgen, a type-safe raw SQL solution without the need for an ORM.

## 🔑 The Core of This Topic
Bun-sqlgen is a type-safe raw SQL solution for Bun, allowing developers to write database queries with the safety and flexibility of TypeScript, without the need for an Object-Relational Mapping (ORM) tool.

## ⚡ 5-Second Key Points
- **Point 1**: Write type-safe SQL queries in Bun.
- **Point 2**: No need for an ORM, full control over SQL.
- **Point 3**: High-performance database interactions.

## 📈 Detailed Breakdown
**Type Safety**
Bun-sqlgen ensures that your SQL queries are type-safe, preventing runtime errors and making your code more maintainable.

**Raw SQL Power**
With Bun-sqlgen, you have full control over your SQL queries, allowing you to write complex queries with ease.

**Performance**
Bun-sqlgen is designed to provide high-performance database interactions, making it ideal for large-scale applications.
