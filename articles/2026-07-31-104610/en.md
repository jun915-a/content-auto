# Building a 6502 Computer from Scratch with a Minitel Terminal

Explore the creative project of Memo-1, a 6502 computer built from scratch, utilizing a Minitel as its terminal.

## 🔑 The Core of This Topic
   Memo-1 is a 6502 computer built from scratch, leveraging a Minitel as its terminal. This innovative project showcases the potential of repurposing vintage technology in modern computing.
   
   ## ⚡ 5-Second Key Points
   - **Point 1**: Harness the capabilities of a 6502 processor in a modern computing setup.
   - **Point 2**: Utilize a Minitel terminal to create a unique and creative computer system.
   - **Point 3**: Learn from this project and apply its principles to your own DIY computing endeavors.
   
   ## 📈 Detailed Breakdown
   **Element 1**: The project began with the selection of a suitable 6502 processor and a Minitel terminal. The team then designed a custom breadboard to house the components and crafted a unique casing to enclose the system.
   
   **Element 2**: The software side of the project involved programming the 6502 processor using assembly language. This involved creating a custom operating system and implementing necessary drivers for the Minitel terminal.
