# Windows CE Dreamcast Community Edition

Windows CE Dreamcast Community Edition（wince-dc）は、DreamcastにWindows CEをインストールするためのプロジェクトです。このプロジェクトは、GitHubでホストされており、コミュニティによる開発とサポートが行われています。Dreamcastは1998年に発売されたセガのゲーム機で、Windows CEをインストールすることで新しい使い方が可能になります。wince-dcプロジェクトは、Dreamcastの機能を拡張し、新しいアプリケーションやゲームを実行できるようにすることを目的としています。
