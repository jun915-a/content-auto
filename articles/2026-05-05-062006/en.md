# Edge Stores Passwords in Clear Text

Microsoft Edge stores passwords in memory in clear text, posing a significant security risk to users, even when the passwords are not in use, as reported on Twitter

## 🔑 The Core of This Topic
Microsoft Edge stores all passwords in memory in clear text, even when unused, which is a significant security concern. 
## ⚡ 5-Second Key Points
- **Point 1**: Passwords are stored in clear text
- **Point 2**: This occurs even when passwords are not in use
- **Point 3**: A significant security risk is posed to users
## 📈 Detailed Breakdown
**Element 1**
The storage of passwords in clear text in Microsoft Edge's memory is alarming, as it makes them easily accessible to potential attackers. 
**Element 2**
This issue is further exacerbated by the fact that these passwords remain in memory even when they are not being used, increasing the window of vulnerability.
> 💡 Insight: This vulnerability can be exploited by malicious actors to gain unauthorized access to sensitive information.
## 🎯 Real-World Impact
- Users' personal data is at risk of being compromised
- Financial information can be stolen
- Identity theft is a potential consequence
## ✨ Conclusion
The storage of passwords in clear text by Microsoft Edge is a serious issue that needs to be addressed promptly to protect users' sensitive information.
