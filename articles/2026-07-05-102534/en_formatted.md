## 🔑 The Core of This Topic
Web-based cryptography relies on clients generating and storing keys, which is a huge security risk. The key is often generated in the browser and is easily accessible to malicious scripts.

## ⚡ 5-Second Key Points
- **Point 1**: Weak keys are generated in the browser.
- **Point 2**: Private keys are stored locally, making them vulnerable to attacks.
- **Point 3**: Web-based cryptography is often used for authentication, which can be hijacked.

## 📈 Detailed Breakdown
**Element 1**
Private keys are stored locally, making them vulnerable to attacks. When a user logs in to a website, their browser generates a session key, which is then used to authenticate their session. However, this private key can be stolen using social engineering tactics.

**Element 2**
The key is often generated in the browser and is easily accessible to malicious scripts. When a user visits a website, their browser generates a key pair, which includes a public key and a private key. However, if a malicious script can access the private key, it can steal the user's identity.
