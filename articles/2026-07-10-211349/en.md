# Learn Algebra by Touch with Wyrm, an Open-Source Soundness Engine

Discover how Wyrm, an innovative app, uses an open-source soundness engine to help users learn algebra through tactile manipulation

## 🔑 The Core of This Topic
Wyrm is a revolutionary app that teaches algebra by touch, leveraging an open-source soundness engine to ensure accuracy and effectiveness. By leveraging a mobile-friendly interface, users can interact with algebraic expressions in a hands-on manner, gradually building their problem-solving skills.
