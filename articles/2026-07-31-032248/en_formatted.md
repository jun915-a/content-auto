# Build a 6502 Computer with a Minitel Terminal

*Insert header image here*

Explore the Memo-1 project: a custom-built 6502 computer that ingeniously uses a vintage Minitel terminal as its display and input device. A unique blend of retro computing and DIY.

## 🔑 The Core of This Topic
The Memo-1 project is a fascinating endeavor to construct a functional 6502-based computer entirely from scratch. It cleverly repurposes a Minitel terminal, a relic of early French videotex systems, to serve as the user interface, providing both display and keyboard input.

## ⚡ 5-Second Key Points
- **Retro Computing Reimagined**: Building a 6502 system from the ground up.
- **Minitel Integration**: Utilizing vintage tech for modern DIY computing.
- **Educational Project**: Deep dive into hardware and system design principles.

## 📈 Detailed Breakdown
**Custom 6502 Board**
The heart of Memo-1 is a custom-designed printed circuit board (PCB) featuring the iconic MOS Technology 6502 microprocessor. This board handles all the core processing, memory management, and I/O operations for the system.

**Minitel Terminal Interface**
Instead of a standard monitor and keyboard, Memo-1 interfaces directly with a Minitel terminal. This requires custom circuitry to translate the computer's output signals into a format the Minitel can understand and to process keyboard input.

> 💡 Insight: Repurposing vintage terminals offers a unique aesthetic and an engaging challenge in interfacing disparate technologies.

**Software and Bootstrapping**
The project involves developing the necessary firmware and basic software to boot the 6502 processor and interact with the Minitel. This includes memory mapping, interrupt handling, and character display routines.
