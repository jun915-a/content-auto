# **TLS 1.2 および DTLS 1.2 の OBSOLETE キー交換メソッドの非推奨**

RFC 10015 では、TLS 1.2 と DTLS 1.2 の OBSOLETE のキーシェアリングメソッドを非推奨にしました。この変更は、セキュリティと信頼性を強化することを目的としています。

## 📌 このトピックの本質
TLS 1.2 と DTLS 1.2 の OBSOLETE のキーシェアリングメソッドを非推奨にします。非推奨のメソッドは RSA key exchange と PSK key exchange です。

## 🎯 5秒で分かるポイント
- **Point 1**: OBSOLETE のキーシェアリングメソッドはセキュリティ上の脆弱性をもたらします。
- **Point 2**: 非推奨のメソッドは TLS 1.3 と DTLS 1.3 ではすでに非推奨です。
- **Point 3**: この変更はセキュリティと信頼性を強化することを目的としています。

## 📊 詳細解説
**Element 1**: OBSOLETE のキーシェアリングメソッドは RSA key exchange と PSK key exchange です。これらのメソッドはセキュリティ上の脆弱性をもたらします。たとえば、 RSA key exchange はパラメータが不正に設定されている場合に脆弱性をもたらします。

**Element 2**: 非推奨のメソッドは TLS 1.3 と DTLS 1.3 ではすでに非推奨です。これは、セキュリティ上の脆弱性を排除するために実施されました。

> 💡 ポイント: OBSOLETE のキーシェアリングメソッドを非推奨にすることで、セキュリティと信頼性を強化できます。
