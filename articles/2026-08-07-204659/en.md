## 📈 Detailed Breakdown
**Buffer Overflow Attacks**
A buffer overflow occurs when more data is written to a buffer than it is capable of holding, causing the extra data to spill over into adjacent memory spaces. This can be exploited by attackers to execute malicious code.

**SQL Injection Attacks**
SQL injection occurs when user input is not properly sanitized, allowing attackers to inject malicious SQL code into a database. This can result in unauthorized access to sensitive data.
