# Forge: AI Reliability

Forge boosts LLM tool-calling reliability with an open-source layer, enhancing performance from 53% to 99% on agentic tasks

## 🔑 The Core of This Topic
Forge is an open-source reliability layer for self-hosted LLM tool-calling, developed by Antoine Zambelli, AI Director at Texas Instruments. It adds domain-and-tool-agnostic guardrails to improve model performance.
## ⚡ 5-Second Key Points
- **Improved Accuracy**: Forge takes an 8B model from 53% to 99% on agentic tasks
- **Open-Source**: Available for use and modification on GitHub
- **Self-Hosted**: Designed for self-hosted LLM tool-calling
## 📈 Detailed Breakdown
**Reliability Layer**
Forge's reliability layer provides a crucial foundation for LLM tool-calling, allowing for more accurate and consistent results.
**Domain-Agnostic Guardrails**
These guardrails enable Forge to work effectively across various domains, making it a versatile tool for AI development.
> 💡 Insight: By leveraging Forge, developers can significantly enhance the performance of their LLM models.
