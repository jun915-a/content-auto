## 🔑 The Core of This Topic
Recursive filters are a type of filter used in signal processing to remove noise and emphasize specific frequencies in a signal. They are called recursive because they use previous values of the filter output to calculate the next value. In this article, we will explore four types of recursive filters: Simple Moving Average (SMA), Exponential Moving Average (EMA), Low-Pass filter, and a tiny Kalman filter.

## ⚡ 5-Second Key Points
- **Point 1**: SMA and EMA filters are used for smoothing and trend following.
- **Point 2**: Low-Pass filter is used for removing high-frequency noise.
- **Point 3**: Tiny Kalman filter is used for state estimation in dynamic systems.

## 📈 Detailed Breakdown
**SMA Filter**
The SMA filter calculates the average of a set of values and returns the average as the filter output. It is a simple and effective filter for smoothing out noise in a signal.

**EMA Filter**
The EMA filter calculates the weighted average of a set of values, where the weights decrease exponentially as they get older. This makes it more responsive to recent changes in the signal.

**Low-Pass Filter**
The Low-Pass filter removes high-frequency components from a signal by calculating the weighted sum of the signal and its previous values.
