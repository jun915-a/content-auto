# Which Tools Do AI Coding Agents Prefer? A 17K-Run Deep Dive

Discover the most installed tools by Claude, Codex, and Cursor after analyzing 17,000 coding agent runs. Uncover surprising trends and how these choices shape modern AI-driven development.

## 🔑 The Core of This Topic
AI-powered coding agents like Claude, Codex, and Cursor rely on tool selection to enhance productivity. This study examines which tools these agents prefer based on 17,000 real-world runs, revealing patterns in automation, debugging, and workflow optimization.

## ⚡ 5-Second Key Points
- **GitHub CLI** tops the list as the most frequently installed tool, reflecting its role in version control automation.
- **VS Code** is the dominant editor, with extensions like **Python** and **JavaScript** being the most sought-after.
- **Docker** and **npm** are critical for containerization and package management, respectively.

## 📈 Detailed Breakdown
**Tool Installation Trends Across Agents**
The data highlights GitHub CLI as the undisputed leader, with over **40%** of agents installing it. This aligns with its seamless integration for Git operations, branch management, and PR automation—key workflows for modern developers. Claude, in particular, shows a strong preference for CLI tools, likely due to its versatility in handling repetitive tasks.

**Editor & Language-Specific Preferences**
VS Code is the default choice for **85%** of agents, underscoring its extensibility and developer-friendly ecosystem. Within VS Code, Python and JavaScript extensions dominate, reflecting the dominance of these languages in AI and web development. Codex, optimized for code generation, leans heavily toward language-specific tools to refine outputs.

> 💡 Insight: **Cursor’s hybrid approach**—balancing CLI efficiency with IDE flexibility—makes it uniquely adaptable to diverse coding scenarios.

**Infrastructure & Package Management**
Docker and npm emerge as top-tier tools for containerization and dependency management, respectively. Agents prioritize these for **scalability and reproducibility**, critical in AI-driven workflows. Cursor, in particular, shows a higher adoption rate for Docker, suggesting a focus on microservices and cloud-native development.

## 🎯 Real-World Impact
- **Faster Onboarding**: Pre-installed tools reduce setup friction, accelerating agent deployment in new projects.
- **Consistency in Workflows**: Standardized tool choices ensure predictable automation, improving reliability.
- **Language-Specific Optimization**: Agents tailor tool selection to language needs, enhancing code quality and maintainability.

## ✨ Conclusion
The 17,000-run analysis reveals a clear hierarchy in tool preferences: **GitHub CLI, VS Code, and Docker** dominate, with language-specific extensions playing a pivotal role. These insights guide developers and AI engineers in optimizing agent configurations for real-world efficiency. The future lies in **dynamic tool selection**, where agents adapt based on project context—ushering in a new era of intelligent, context-aware development.
