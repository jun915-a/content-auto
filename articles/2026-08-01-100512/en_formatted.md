## 🔑 The Core of This Topic
DRAM read disturbance refers to the phenomenon where repeated access to a specific memory location causes neighboring locations to be disturbed, leading to performance degradation and potential security vulnerabilities. This issue is primarily caused by the RowHammer effect and RowPress phenomenon.
## ⚡ 5-Second Key Points
- **Point 1**: RowHammer is a hardware-based vulnerability that exploits the inherent characteristics of DRAM memory.
- **Point 2**: RowPress is a software-based vulnerability that can be exploited through malicious code.
- **Point 3**: Both RowHammer and RowPress can lead to significant performance degradation and security risks.
## 📈 Detailed Breakdown
**RowHammer Effect**
The RowHammer effect is a hardware-based vulnerability that occurs when a row in the DRAM is continuously accessed, causing adjacent rows to be disturbed. This can lead to performance degradation and data corruption.
**RowPress Phenomenon**
The RowPress phenomenon is a software-based vulnerability that can be exploited through malicious code. It occurs when a program repeatedly accesses a specific memory location, causing neighboring locations to be disturbed.
