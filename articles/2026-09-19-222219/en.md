# TIN: Revolutionizing Full-Text Search in PostgreSQL

Discover **TIN**, the open-source full-text search engine for PostgreSQL that combines speed, scalability, and ease of use. Built by PlanetScale, it redefines how developers handle text queries—without sacrificing performance or flexibility.

**TIN** is an open-source full-text search engine designed to integrate seamlessly with PostgreSQL, offering unparalleled speed, scalability, and developer-friendly features. It addresses the limitations of traditional PostgreSQL full-text search while providing a modern, efficient alternative for applications requiring advanced text querying capabilities. Developed by PlanetScale, TIN is a game-changer for developers who need high-performance search without the complexity of standalone solutions like Elasticsearch or Meilisearch.
