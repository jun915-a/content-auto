## 📈 Detailed Breakdown
**Buffer Overflow**
Buffer overflow attacks occur when an application attempts to store more data in a buffer than it is designed to hold, leading to unpredictable behavior. This vulnerability can be exploited using assembly language to execute malicious code.

**Format String Attacks**
Format string attacks involve manipulating the format string of a function to inject malicious code. This type of attack can be particularly devastating when used in combination with buffer overflows.
