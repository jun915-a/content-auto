# Edge Stores Passwords in Clear Text

*Insert header image here*

Microsoft Edge stores passwords in memory, even when unused, posing a significant security risk to users, as highlighted in a recent Twitter post

## The Core of This Topic
Microsoft Edge stores all passwords in memory in clear text, even when unused, which is a significant security concern. 
## 5-Second Key Points
- **Security Risk**: Passwords are stored in clear text
- **Unused Passwords**: Even unused passwords are stored in memory
- **Easy Access**: An attacker can easily access these passwords
## Detailed Breakdown
**Element 1**: The storage of passwords in clear text is a fundamental flaw in Edge's security. 
**Element 2**: This issue is exacerbated by the fact that even unused passwords are stored in memory, increasing the attack surface. 
> Insight: This lack of security measures puts users' sensitive information at risk. 
## Real-World Impact
- Users are at risk of having their passwords stolen
- Attackers can use these passwords to gain access to sensitive information
- This issue undermines the trust users have in Microsoft Edge 
## Conclusion
The storage of passwords in clear text is a critical issue that Microsoft needs to address to ensure the security and trust of its users.
