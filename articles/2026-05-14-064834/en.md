# Needle: AI Tool Calling Model

Cactus open-sourced Needle, a 26M parameter function-calling model for efficient tool use, running at 6000 tok/s prefill and 1200 tok/s decode on consumer devices

## The Core of This Topic
Needle is a 26M parameter model that enables efficient tool use by distilling Gemini tool calling into a compact and fast architecture.

## 5-Second Key Points
- **Fast Performance**: Runs at 6000 tok/s prefill and 1200 tok/s decode on consumer devices
- **Compact Size**: 26M parameter model for efficient function-calling
- **Open-Source**: Released by Cactus for community development and improvement

## Detailed Breakdown
**Model Architecture**
Needle's architecture is designed for speed and efficiency, allowing it to run on consumer devices without sacrificing performance.

**Tool Calling**
The model enables seamless tool calling, allowing users to leverage various tools and functions with ease.
