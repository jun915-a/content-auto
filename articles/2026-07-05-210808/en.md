# OpenWiki: CLI for Agent Documentation

Automate agent documentation for your codebase with OpenWiki, a CLI tool developed by langchain-ai.

## 🔑 The Core of This Topic
OpenWiki is a command-line interface (CLI) designed to write and maintain agent documentation for your codebase. This tool simplifies the process of documenting complex systems and models, making it easier to understand and maintain them.
