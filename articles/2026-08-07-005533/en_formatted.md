# Pokémon Emerald on Raspberry Pi Pico 2

*Insert header image here*

Pokémon Emerald has been successfully ported to the Raspberry Pi Pico 2, achieving 60 fps HDMI output without an emulator.

## 🔑 The Core of This Topic
The Pokémon Emerald game has been recompiled from ARMv4T to Cortex-M33, allowing it to run on the RP2350 microcontroller. 
## ⚡ 5-Second Key Points
- **Porting Success**: Pokémon Emerald now runs on Raspberry Pi Pico 2.
- **No Emulator**: The game runs directly on the microcontroller.
- **High Frame Rate**: Achieves 60 fps HDMI output.
## 📈 Detailed Breakdown
**Recompilation Process**
The game was recompiled to work with the Cortex-M33 architecture, enabling it to operate on the Raspberry Pi Pico 2.
**Software Video Hardware**
The Game Boy Advance's video hardware is reimplemented in software, facilitating the game's execution on the microcontroller.
