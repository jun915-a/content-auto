# Clojure 1.13

Clojure 1.13 adds support for checked keys. This new feature enhances the security and reliability of Clojure applications by ensuring that keys used to access maps are valid. The update is part of Clojure 1.13 alpha1, which was recently announced.

## このトピックの本質
Clojure 1.13 は、チェックされたキーをサポートします。
## 5秒で分かるポイント
- **Point 1**: キーの検証が可能
- **Point 2**: アプリケーションのセキュリティと信頼性が向上
- **Point 3**: Clojure 1.13 alpha1 で利用可能
## 詳細解説
**Element 1**: チェックされたキーは、マップへのアクセスをより安全に行えるように設計されています。
**Element 2**: この機能により、開発者はバグを早期に検出できるようになります。
