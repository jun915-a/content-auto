## 📈 Detailed Breakdown
**Buffer Overflow Attacks**
A buffer overflow occurs when more data is written to a buffer than it is designed to hold. This can cause the program to crash or execute malicious code.

**Format String Vulnerabilities**
Format string vulnerabilities occur when user input is used to format strings, allowing an attacker to inject malicious code.

> 💡 Insight: These vulnerabilities are often the result of poor coding practices and a lack of input validation.

## 🎯 Real-World Impact
- The Morris Worm, a 1988 computer worm that infected an estimated 6,000 computers.
- The Heartbleed Bug, a 2014 vulnerability in OpenSSL that exposed sensitive information.
- The ShellShock Bug, a 2014 vulnerability in the Bash shell that allowed attackers to execute malicious code.
