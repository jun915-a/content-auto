# **ブラウザ上でQuake 3 マップを編集できるQ3Editが登場**

Quake 3 マップをブラウザ上で簡単に編集できる、Radiant-style ライアウトを搭載したレベルエディター Q3Edit の紹介。

## 📌 このトピックの本質
Quake 3 マップの編集とプレイをブラウザ上で行える新しいレベルエディター Q3Edit が登場しました。このエディターは、Radiant-style ライアウトを搭載し、ブラシとパッチの編集、CSG、地形スクラッチング、エンティティの編集など、Quake 3 のレベル編集に必要な機能をすべて備えています。

## 🎯 5秒で分かるポイント
- **Point 1**: Quake 3 マップをブラウザ上で簡単に編集できる。
- **Point 2**: Radiant-style ライアウトを搭載しており、Quake 3 のレベル編集に慣れているユーザーもすぐに慣れて使える。
- **Point 3**: エンティティの編集機能が備わっているため、より高度なレベル編集が可能。

## 📊 詳細解説
**Element 1: ブラシとパッチの編集**
Q3Edit では、Quake 3 のレベルエディターでおなじみのブラシとパッチの編集 functionality を搭載しています。地形を自由に編集でき、クライアント側での描画が高速になります。

**Element 2: CSG**
Q3Edit では、CSG (Constructive Solid Geometry) の機能も搭載されています。これにより、複雑な形状を簡単に作成できます。
