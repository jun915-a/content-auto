# Fast and Efficient Hash Map and Hash Set in C++

A C++ implementation of a fast hash map and hash set using the efficient hopscotch hashing algorithm.

## 🔑 The Core of This Topic
Hopscotch hashing is an innovative algorithm for implementing hash maps and hash sets. It uses a combination of chaining and open addressing to achieve high performance and low memory usage. This implementation provides a fast and efficient way to store and retrieve key-value pairs.

## ⚡ 5-Second Key Points
- **Point 1**: Fast lookup, insertion, and deletion operations.
- **Point 2**: Low memory usage and cache efficiency.
- **Point 3**: Highly customizable and configurable.

## 📈 Detailed Breakdown
**Hopscotch Hashing Algorithm**
Hopscotch hashing uses a combination of chaining and open addressing to achieve high performance. It uses a fixed-size array to store key-value pairs and a hopscotch table to store the indices of the occupied slots. This allows for fast lookup and insertion operations.

**Key Features**
- Fast lookup, insertion, and deletion operations.
- Low memory usage and cache efficiency.
- Highly customizable and configurable.
