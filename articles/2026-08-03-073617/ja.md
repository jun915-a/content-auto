# **TLS 1.2 is in Feature Freeze: 次のステップはなにか?**

TLS 1.2 の機能フリーズが発表されました。RFC 9851 を通じて、TLS 1.2 の開発が終了されました。ここでは、その意味合いと次のステップについて紹介します。

## このトピックの本質
TLS 1.2 の機能フリーズは、TLS 1.2 の開発が終了したことを意味します。TLS の標準化プロセスでは、機能フリーズは新機能の追加が終了し、バグ修正のみの段階であることを示します。

## 5秒で分かるポイント
- **Point 1**: TLS 1.2 の機能フリーズにより、TLS 1.3 への移行が促進されます。
- **Point 2**: 次に開発が進むのは TLS 1.3 です。
- **Point 3**: TLS 1.2 のバグ修正は継続されます。

## 詳細解説
**Element 1**: TLS 1.2 の機能フリーズは、TLS の標準化プロセスの重要なステップです。TLS 1.2 の開発が終了すると、開発者は TLS 1.3 の開発に集中することができます。TLS 1.3 は、セキュリティ強化とパフォーマンスの向上を目的として開発されています。
