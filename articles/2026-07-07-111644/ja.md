# **Mac用高速ファイルマネージャが誕生!**

Macユーザーなら聞いたことがあるかもしれない「ダウンロードフォルダの整理」問題に、開発者が答えを出した。Fast、native Mac file managerが誕生!

## 📌 このトピックの本質
macOS用に高速で、ネイティブのファイルマネージャを開発した開発者が、自身のプロジェクトについて紹介します。
## 🎯 5秒で分かるポイント
- **ポイント1**: macOS用の高速ファイルマネージャに加え、フィルタリングやフュージー検索機能が搭載。
- **ポイント2**: Electronを使わずに開発されたため、軽量かつ高速。
- **ポイント3**: 9MB以下のサイズでダウンロード可能。
## 📊 詳細解説
**Filter機能**
このファイルマネージャには、ダウンロードフォルダ内のファイルをフィルタリングする機能が搭載されています。開発者自身は、ダウンロードフォルダを整理するためにこの機能を使っていました。
**Fuzzy Find機能**
また、開発者はフュージー検索機能にも注力しています。この機能により、ファイル名を部分的に入力することで、目的のファイルを検索できます。
> 💡 ポイント: このファイルマネージャは、macOS用に開発されたため、ネイティブの感覚でファイルを管理できます。
