# Gnomon: Git for PostgreSQL Data, Powering AI Agents

Gnomon transforms PostgreSQL into a version-controlled, agent-friendly data layer. Track changes, sync data, and enable seamless collaboration—just like Git for databases.

**Gnomon** is an open-source tool that brings **Git-like version control** to **PostgreSQL databases**, enabling developers and AI agents to manage, track, and collaborate on data changes efficiently. Unlike traditional database tools, Gnomon integrates **Git workflows** (branching, merging, diffing) into PostgreSQL, making it ideal for **data versioning, auditing, and agent-driven automation**.
