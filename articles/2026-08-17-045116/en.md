# Unlocking Efficient Data Storage with Prolly

Prolly is a content-addressed ordered map built on prolly trees, offering a unique approach to data storage and retrieval.

## 🔑 The Core of This Topic
Prolly is a content-addressed ordered map, meaning it stores data in a way that allows for efficient lookup, insertion, and deletion of key-value pairs. This is achieved through the use of prolly trees, a type of data structure that provides fast and reliable data storage.
