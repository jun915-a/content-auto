# Needle: AI Model

Cactus open-sourced Needle, a 26M parameter model for function-calling, running at 6000 tok/s prefill and 1200 tok/s decode on consumer devices.

Needle is a function-calling model that enables efficient tool use. It has 26M parameters and achieves high performance.
