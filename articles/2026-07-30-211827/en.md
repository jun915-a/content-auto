# Building a 6502 Computer from Scratch with a Minitel Terminal

A project to build a 6502 computer from scratch using a Minitel as its terminal, exploring the inner workings of computer architecture and the possibilities of retro computing.

## 🔑 The Core of This Topic
The Memo-1 project is an attempt to build a 6502 computer from scratch using a Minitel as its terminal. This project delves into the inner workings of computer architecture, exploring the possibilities of retro computing and the challenges of building a functional computer from basic components.

## ⚡ 5-Second Key Points
- **Point 1**: Utilize a Minitel as the terminal for the 6502 computer.
- **Point 2**: Design and build the computer's hardware components from scratch.
- **Point 3**: Implement a 6502 processor-based system.

## 📈 Detailed Breakdown
**The Hardware Components**
The project involves designing and building various hardware components, including the central processing unit (CPU), memory, and input/output (I/O) systems. These components must be carefully crafted to work together seamlessly, ensuring the computer's overall functionality.

**The Software Components**
In addition to the hardware components, the project also involves developing the software components, including the operating system and application programs. These components must be designed to take advantage of the 6502 processor's capabilities and the Minitel terminal's features.

> 💡 Insight: By building a 6502 computer from scratch, the project offers a unique opportunity to gain a deeper understanding of computer architecture and the possibilities of retro computing.

## 🎯 Real-World Impact
- The project demonstrates the feasibility of building a functional computer from basic components.
- It showcases the capabilities of the 6502 processor and the Minitel terminal.
- The project's results can be used as a starting point for further research and experimentation in computer architecture and retro computing.
