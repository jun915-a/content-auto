# Toit v2.0.0: A Leap Forward in Embedded & Edge Computing

Toit v2.0.0 redefines embedded and edge programming with a **faster runtime, richer tooling, and cross-platform flexibility**. This major update unlocks new possibilities for developers targeting constrained devices, offering a modern, secure, and efficient alternative to legacy solutions.

**Toit v2.0.0** marks a pivotal milestone in the journey of the Toit programming language, designed for **embedded systems, IoT, and edge computing**. Built on a **lightweight, secure runtime**, Toit empowers developers to write **high-performance, portable code** that runs seamlessly on microcontrollers, Raspberry Pis, and even cloud environments. This version introduces **major improvements** in speed, developer experience, and ecosystem support, making it a compelling choice for next-gen embedded development.
