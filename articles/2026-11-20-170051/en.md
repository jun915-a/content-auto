# Floppy3.5: Tiny NAS Meets WiFi Magic on a Floppy Disk

Meet **Floppy3.5**—a portable WiFi NAS disguised as a 3.5-inch floppy disk! This quirky project turns vintage tech into a modern file-sharing hub with surprising capabilities. Perfect for makers, tinkerers, and nostalgia lovers, it’s a playful yet functional twist on storage. Dive in to see how it works and why it’s a hidden gem for DIY enthusiasts.

## 🔑 The Core of This Topic
A **Floppy3.5** is a creative DIY project that repurposes an old **3.5-inch floppy disk drive** into a **portable WiFi Network Attached Storage (NAS)**. By integrating a Raspberry Pi, WiFi module, and microSD card, it transforms a retro storage device into a compact, wireless file server. The project blends **retro aesthetics with modern functionality**, offering a fun way to share files over a local network or even the internet—all while keeping the charm of vintage tech.

## ⚡ 5-Second Key Points
- **Vintage meets WiFi**: A floppy disk drive becomes a wireless file server.
- **Portable & hackable**: Runs on a Raspberry Pi, customizable for any use case.
- **No power supply needed**: Can be powered via USB, making it truly portable.

## 📈 Detailed Breakdown
**The Hardware Foundation**
At its heart, the Floppy3.5 relies on a **Raspberry Pi (Zero or similar)** tucked inside the floppy drive housing. The drive’s original motor and mechanics are repurposed for cooling, while the **WiFi module** (like an ESP8266) enables wireless connectivity. A **microSD card** serves as the storage medium, holding files shared via a simple web interface or SMB protocol. The result? A **self-contained, plug-and-play NAS** that fits in the palm of your hand.

**Software & Functionality**
The project uses **Linux-based software** (often **Raspberry Pi OS**) to set up a lightweight web server or **Samba share**, allowing users to access files wirelessly. Some builds even include **Plex or Jellyfin** for media streaming, turning the floppy into a mini home server. The **open-source nature** of the project means users can tweak firmware, add sensors, or even integrate IoT features—like a **WiFi-enabled weather station** disguised as a floppy.
