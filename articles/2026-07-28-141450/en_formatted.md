As the garbage collector scans the heap, it identifies free memory blocks and merges them to create larger contiguous blocks. This reduces memory waste and improves memory efficiency.

**Concurrent Mark-and-Sweep**
The collector uses concurrent mark-and-sweep to minimize pause times. This involves marking live objects in parallel and sweeping the heap in one go, reducing the overall collection time.
