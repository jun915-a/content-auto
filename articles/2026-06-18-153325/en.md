# AMD Removes Memory Encryption

AMD quietly drops memory encryption from consumer Ryzen CPUs, leaving users vulnerable to security threats without their knowledge

## 🔑 The Core of This Topic

- **Point 2**: The change affects consumer Ryzen CPUs
- **Point 3**: Users may be vulnerable to security threats
