# Steam Machine 発売

*ここに見出し画像を挿入*

Steam Machine が今日発売されました。Steam の世界에서新たな体験を味わうことができます。Steam Machine は PC ゲームをテレビでプレイできるように設計されています。さまざまなハードウェア メーカーから提供される Steam Machine を購入することで、テレビでSteamのゲームを楽しむことができます。Steam Machine の発売により、PC ゲーミングの世界がさらに広がります。

## このトピックの本質

- **Steam のゲーム**: 数千のゲームが利用可能

Steam Machine の発売は PC ゲーミングの世界に新たな息吹をもたらします。
